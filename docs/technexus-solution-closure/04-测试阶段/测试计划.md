## 1. 测试目标

验证 TechNexus V1 在真实 MySQL 上的认证、权限、内容、需求、审核、免费定价和文件入口主链路；验证已确认的 10/20 QPS Alpha 性能护栏；复核 Spring Boot + DDD、统一命名、API 契约、安全与恢复要求。测试结论用于阶段四门禁，不等同于真实用户上线许可。

## 6. 测试策略

采用风险优先：认证/授权、审核/定价、数据恢复和文件链路优先于页面装饰。自动化覆盖可重复的领域、HTTP、构建、依赖和负载检查；外部服务与浏览器场景不得以 Mock 结果冒充端到端结论。回归至少包含受改动安全过滤器、异常映射、OpenAPI、全 Maven、双前端和黑盒主链。

## 12. 缺陷管理

严重：可能越权、丢失核心数据、恶意文件进入可用态或无法恢复，阻断上线；重要：核心行为/契约错误或 Must 缺少有效验证，阶段通过需明确批准；一般：有替代路径且不改变核心事实；建议：质量增强。缺陷按“新建→分析→修复→回归→关闭”管理，延期必须关联需求、风险接受人和复测日期。
