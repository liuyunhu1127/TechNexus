## 3. 修复项

1. 全局增加“跳到主要内容”链接，`main` 使用稳定目标和可编程焦点；
2. 为键盘焦点增加高对比度 `:focus-visible` 轮廓；
3. 导航、按钮和表单控件的最小高度统一为 44 CSS px；
4. 移动端头部允许换行，动作区允许换行，避免 390px 视口横向溢出；
5. 输入边框加深，提高非文本界面对比；
6. 登录页增加独立 title，站点增加默认标题、主题色和 OpenGraph 类型；
7. 增加自定义 404/错误页，包含可感知错误、返回操作和 `noindex,nofollow`；
8. 增加 `robots.txt`，公开页面允许索引，编辑和文件路由禁止抓取。
