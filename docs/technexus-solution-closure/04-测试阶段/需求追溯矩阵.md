## 1. 追溯规则

- 50 个 Must FR、5 个 Should FR 和 24 个 NFR 均在本矩阵出现；
- “覆盖”表示已绑定验证或缺口用例，“已验证”才表示当前证据足以判定通过；
- 设计引用为 DES-ARCH/UX v1.0、DES-DETAIL v1.0.1、DES-DB v1.0.3、DES-API v1.0.9、DES-OAS v1.0.8；
- 代码基线统一为 `master@9db66ad` 加阶段四修复，模块、包和数据库名称遵循 12 个 `technexus-*`、`com.technexus`、`tn_`；
- P1 延期保留历史关系，不计为 V1 Core 实现失败。
