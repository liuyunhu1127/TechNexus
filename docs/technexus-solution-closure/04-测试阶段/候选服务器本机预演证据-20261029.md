## 1. 结论

候选服务器专项的可重复脚本、门禁防误判和本机缩短版预演已经完成。三个负载窗口的吞吐、延迟、5xx 和传输错误自动检查均通过，Prometheus 成功采集 JVM、GC、线程、Hikari 和进程指标；线程数稳定、Hikari 无等待、主机可用内存未下降。

本结果不能关闭 `TNX-GATE-004` 或 `RTM-GAP-005`：目标是 localhost、稳定窗口仅 60 秒而非 30 分钟、数据集非 Alpha 规模、目标服务器/数据库主机清单和网络边界不存在，数据库前后快照在本轮本机预演中显式跳过。状态继续为 `BLOCKED_EXTERNAL`。

## 7. 候选机正式执行条件

1. 提供可从独立负载机访问的候选 HTTPS URL、目标机和数据库主机登录权限；
2. 候选应用使用 Java 21，并记录 CPU、内存、磁盘、网络、OS、MySQL 和容器版本；
3. 准备接近 Alpha 规模且不含真实个人信息的数据；
4. 在目标机并行运行 30 分钟主机采样，在独立负载机执行候选模式；
5. 复核 10/20 QPS、30 分钟长稳、JVM heap/GC/thread、Hikari、MySQL counters/慢 SQL、磁盘/网络与文件/批处理队列；
6. 确认无资源持续增长、连接泄漏、错误率超标或队列堆积后，才可人工关闭 `TNX-GATE-004/RTM-GAP-005`。
