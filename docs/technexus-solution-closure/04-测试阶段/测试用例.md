## 1. 用例组织规则

- 编号为 `TC-<域>-<序号>`，结果以最后一次有效执行为准；
- 单元用例由 Maven 报告聚合，系统用例由 `scripts/system-smoke.ps1` 的原子断言聚合；
- “通过”只代表列出的环境和观察点，不推导未执行的外部服务或浏览器结果；
- 每个 Must/Should 在 RTM 中关联用例、缺口或明确延期。

## 4. 参数与组合

| 参数 | 有效等价类 | 无效等价类 | 边界 | 组合约束 |
|---|---|---|---|---|
| 角色 | 匿名/用户/运营/管理员 | 伪造 authority | 所有者/非所有者 | HTTP 方法 × 资源状态 × Scope |
| 版本 | 当前版本 | 旧版本/未来版本 | 0、当前、当前-1 | 修改/提交/审核/定价均需比较 |
| Idempotency-Key | 新 UUID/相同请求重放 | 缺失/同键异请求 | 36 字符 UUID | actor × method × path × body hash |
| 文件大小 | 1B~100MB | 0、>100MB | 1、10MB、100MB | purpose × MIME × Hash × owner |
| QPS | 10 稳态、20 突发 | 超出护栏 | 10/20 | contents/demands/search 混合 |

## 5. 权限与安全场景

| 主体 | 资源 | 操作 | 预期授权结果 | 越权验证 | 审计验证 |
|---|---|---|---|---|---|
| 匿名 | 草稿内容/需求 | GET | 404/不可枚举 | 直接 UUID | 状态不改变 |
| 非所有者用户 | 草稿内容/需求 | GET/PATCH | 403 或 404 | 双用户替换 ID | 状态不改变 |
| 普通用户 | 管理 API | GET/POST | 403 | 有效 Bearer Token | 稳定 Problem code |
| 管理员 | 审核/定价 | POST | 按权限允许 | 使用普通用户对照 | 任务和价格历史保留 |
| 文件所有者/他人 | 私有文件 | 下载 | owner/Relation 允许，其余 404 | 替换 fileId | 待真实 E2E |

## 6. 异常与恢复场景

| 故障/异常 | 注入方式 | 期望用户表现 | 期望系统状态 | 恢复验证 |
|---|---|---|---|---|
| 缺失 CSRF/Origin | 删除请求头 | 403 CSRF_INVALID | 会话不轮换 | 后续合法刷新成功 |
| Refresh 重用 | 再用旧 Cookie | 401 | 令牌族撤销 | 重新登录可恢复 |
| 对象存储离线 | 127.0.0.1:9000 无服务 | 503，可重试 | 不伪标上传完成 | 服务恢复后重试（待环境） |
| 数据库恢复 | dump 到临时库 | 不影响在线测试库 | 37 表/关键行数一致 | 临时库清理 |
