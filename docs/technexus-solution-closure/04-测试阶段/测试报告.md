已修复并回归：

- `TST-DEFECT-001` 缺失 Origin 时不可变集合 `contains(null)` 触发异常并误报 401；修复为稳定 403；
- `TST-DEFECT-002` Spring Security 的 `sendError(403)` 二次分派后误报 401；改为直接输出 Problem JSON；
- `TST-DEFECT-003` 对象存储/扫描不可用被映射为 400 且 OpenAPI 漏列 503；统一为 503 并补契约与单测。
- `TST-DEFECT-004` 未捕获异常进入 `/error` 后被安全链伪装为 401；放行 ERROR dispatcher，并以真实 HTTP 断言保持 500。
