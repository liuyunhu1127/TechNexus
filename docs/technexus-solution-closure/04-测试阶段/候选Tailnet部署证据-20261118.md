# 候选 Tailnet 与公网 Funnel 部署证据（2026-11-18）

## 1. 结论

TechNexus 候选版本已部署到 Tailscale 候选节点。MySQL、ClamAV、Spring Boot、Nuxt 用户端、Vue 管理端和 MinIO 对象存储均已启动且容器健康检查通过，Flyway 已从空库执行到 V14。本记录保留当时的验证结果，实际节点信息和管理员邮箱由运维侧保管。

经用户批准，Tailscale Funnel 已发布公网用户端/API（443）和文件传输端点（10000）。管理端（8443）及原始 MinIO API（9000）仍为 `tailnet only`，数据库、ClamAV、MinIO Console 和后端原始端口未直接暴露。真实 HTTPS 文件直传、浏览器 CORS 预检、后端内部对象检查、ClamAV CLEAN 扫描、授权下载和字节完整性验证均已通过，并断言预签名上传、下载 URL 使用 10000 端口。该部署仍不能关闭要求独立负载机的 `TNX-GATE-004`，也不能解释为生产上线批准。

Flyway 输出一条兼容性提示：当前依赖验证到 MySQL 8.1，而实际运行 MySQL 8.4。迁移和应用启动均成功，但正式生产评审仍应确认 Flyway 版本对 MySQL 8.4 的官方支持范围。

Windows 客户端无法在线访问证书吊销服务，初始 Schannel 校验返回 `CRYPT_E_REVOCATION_OFFLINE`。复验使用 `curl --ssl-no-revoke`，只跳过在线吊销查询，仍保留证书链和主机名校验；三个入口均成功。候选网络放行证书吊销端点后应再执行默认吊销检查。

## 6. 公网暴露风险记录

- 注册、登录和公开 API 会接收互联网扫描、撞库、垃圾注册和自动化请求，应补充边缘限流、告警和封禁策略；
- 文件传输端点会接收互联网流量，虽有权限、对象范围和 ClamAV 扫描，仍需关注恶意文件、存储配额和带宽滥用；
- Funnel 当前为 Tailscale 提供的公网代理能力，受其可用性、支持端口和带宽策略约束；
- 尚未完成独立渗透测试、异机备份恢复和告警送达验证，因此当前只定位为候选公网环境，不承载敏感生产数据。
