# TNX-GATE-007 安全暴露面本机准备证据（2026-11-04）

## 1. 结论

应用侧本机安全基线已增强并通过：Spring Boot API 返回 CSP、nosniff、DENY、Referrer-Policy、Permissions-Policy；认证 Cookie 的 Secure/HttpOnly/SameSite=Strict 自动断言通过；Nuxt 生产产物可启动且首页四类安全头齐全。代理头默认不信任，仅允许在应用端口私有且所有请求经过可信反向代理时显式启用。

本结果不是候选公网渗透证据。没有域名/证书、反向代理、防火墙或独立网络位置，未执行 TLS/HSTS/HTTP 跳转/公网端口和授权渗透测试，故 `TNX-GATE-007` 保持 `BLOCKED_EXTERNAL`，`RTM-GAP-006/TST-RISK-004` 不关闭。
