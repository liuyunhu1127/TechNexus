## 5. 专家意见与用户卡点

- 优点：Spring Boot + DDD 和命名约束保持；全量构建 98/98、真实 MySQL 和 HTTP 52/52 通过；发现并修复 3 个安全/错误契约问题；本机性能和数据库恢复已有可重复脚本/记录；
- 必须处理问题：实现同 Hash 的对象复用与独立 File Relation；配置非同主机备份并完成恢复；使用真实 S3/ClamAV 验证上传/扫描/隔离/下载；
- 剩余风险：目标服务器性能、Java 21 运行时、浏览器/a11y/SEO、可观测性、HTTPS/端口和渗透测试；
- 改进建议：将系统与性能脚本纳入 CI/候选环境，持久化原始性能样本，补页面和运维自动化。
